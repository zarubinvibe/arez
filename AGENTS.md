# Arez — правила репозитория

Арес семьи Olympuz: red-team, который доказывает дыру исполнением и запирает её регрессией RED→GREEN,
а не отчётом. Нативный Деймос фаз A–D, отдельный устанавливаемый инструмент. Полная цель и требования —
[queue/GOAL.md](queue/GOAL.md) (в приватном доме), порядок фаз — [docs/MASTER-PLAN.md](docs/MASTER-PLAN.md).

## Доктрина (нарушение = откат правки, не спор)

1. **Находка засчитана только через исполненный observed-RED.** Тест краснеет на дырявом дереве, зеленеет
   после фикса. Отчёт «выглядит небезопасно» без воспроизведения — не находка, а пересказ.
2. **Полый тест отвергается.** Тест, зелёный и ДО фикса, ничего не воспроизводит — это театр. До-фиксный
   тест, убитый сигналом, — инфра-сбой, не RED.
3. **Генератор не судит свой патч.** Вердикт — exit-код гейта, который гонит координатор в своём процессе,
   вне досягаемости атакующего агента. Свой патч чистым не объявляют.
4. **Цель бьётся только на 127.0.0.1, под своей seatbelt, ноль host-egress.** Дыре, которой нужен реальный
   выход в сеть, честно ставят `HELD` недоказуемая, а не выдают за победу.
5. **Fail-closed.** Мусор на входе (невалидный код, пустой манифест, непроверяемый бинд) не открывает вердикт.

## Стек

TypeScript, Node 22+ (целевой Node 24 с нативным type stripping), Bun поддерживается. **Ноль внешних
зависимостей**, только стандартная библиотека Node. ESM-only. Гейт: `node bin/arez.ts gate` =
`node --test` (0 fail, 0 skip) + `catalog` + `doctor` + приёмочный сценарий Деймоса A–D.

## Вендоренный код

Ядро olympuz (5 примитивов: gate/loop/oracle/sandbox/land-gate-honesty) вендорено в `vendor/olympuz/`,
пиненое по коммиту в `vendor/olympuz/PINNED.json`. Лицензия репозитория — **Apache-2.0**, потому что несёт
вендоренный код olympuz. **Вендоренные байты не правят без репина**: скраб/обновление → пересчёт sha256 в
PINNED.json тем же коммитом, иначе `arez doctor` краснеет. strix — только локальный референс-стенд, не
зависимость продукта.

## Перекрёстная проверка: генератор не судит себя

Код пишет один поставщик модели, **проверяет другой** (claude пишет — codex читает, и наоборот). Совпадение
исполнителя и проверяющего — отказ: модель не видит собственную слепую зону. Проверяющему дают модель
угрозы и список того, что искать; ответ — находки вида `путь:строка | дефект | сценарий | починка`.

## Правописание

Без буквы «ё» там, где её нет в каноне семьи. Без длинного тире (дефис). Смешение латиницы и кириллицы
внутри слова — ошибка. Комментарии и сообщения об ошибках по-русски, код и идентификаторы латиницей.

## Работа

- `/ponytail` всегда: простейшее работающее решение. YAGNI, stdlib, платформа, одна строка — до кастома.
  Не режут: валидацию на границе доверия, обработку ошибок, безопасность, обратимость, тесты инвариантов.
- Каждый нетривиальный алгоритм оставляет один прогоняемый тест, падающий при поломке логики.
- Коммиты: `<type>: <описание>`. Push, merge, PR, публикация — только с явного разрешения владельца.
