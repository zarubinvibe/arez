# Сканер Ареса: secret-scan

**Класс:** Секреты

gitleaks по байтам файлов до посадки: exit 1 на утёкшем ключе. Вакуум-guard: ноль просканированных файлов даёт exit 3, а не зелёный вердикт, чтобы пустой скан не сошёл за чистый.

## Место в цепочке

Этот сканер стоит на сиденье Ареса и объявлен в `catalog/skills.json` (REQ-19: ровно шесть на сиденье).
Деймос оркестрирует его в цепочку recon->exploit->prove и сводит его exit-код в вердикт кампании.
Находка засчитывается только через исполненный observed-RED (см. `AGENTS.md`): отчёт без воспроизведения
- не находка. Опасные способности сканера (Bash и сеть для запуска эксплойтов) не стоят на сиденье
постоянно: узел, которому они нужны, несёт риск-флаг D8 и проходит человека один раз.

## Полный runnable-плейбук

Полное тело сканера - это скилл `olympuz-secret-scan`, который ставится в каталог скиллов агента (Claude Code /
Codex) отдельно. Этот файл - объявление и контракт: что сканер даёт цепочке и по каким правилам его вердикт
попадает в гейт. strix остаётся только локальным референс-стендом, не зависимостью продукта.
